# 前端视觉素材

这里的八张 PNG 是用户提供的食堂储值卡系统素材的正式副本。页面设计和实现以这些文件及 [三张页面视觉稿](../../design/reference/README.md) 为视觉输入；早期页面设计文档不作为验收依据。原图保留在 `frontpage/canteen-ui-assets/` 供溯源。

## 视觉方向

- 以食堂场景、蓝色到薄荷绿的渐变和清晰的餐费数字建立识别度。建议页面稿先采用品牌蓝 `#168FF0`、薄荷绿 `#38DDB6`、浅蓝白 `#F5FBFF`、深蓝文字 `#17324D`、成功绿 `#17B785`，再结合实际素材与对比度调整为设计变量。
- 中文正文采用清晰的无衬线字族，金额与时间使用等宽数字。员工页面保持轻快；管理页面优先保证表单、流水和对账信息可读；终端屏优先保证远距离可辨认。
- 图片承担品牌识别、场景和状态表达。真实就餐码、金额、错误和操作按钮保持清晰，不被图片或渐变遮挡。

## 素材用途

| 文件 | 指定用途 |
| --- | --- |
| `app-logo.png` | 登录页及应用标识；保留图形比例与透明边缘。 |
| `login-cafeteria-bg.png` | 员工登录页主背景；按屏幕裁切，保证表单文字和输入框可读。 |
| `home-header-bg.png` | 员工首页顶部场景背景；重要余额信息置于有足够对比度的区域。 |
| `phone-qr-illustration.png` | 登录引导或就餐码说明插画；图中的二维码只是插画，不能代替真实动态码。 |
| `default-avatar.png` | 员工 H5 缺少照片时的头像占位；不在核销屏上充当身份核验照片。 |
| `success-illustration.png` | 消费成功状态的辅助插画；金额和结果文字仍须独立清晰显示。 |
| `scan-frame.png` | 终端等待扫码状态的装饰性提示；终端实际由 USB 扫码枪读取，界面不得暗示相机扫描。 |
| `footer-waves.png` | 登录、员工首页等简单页面的底部装饰；不能遮挡按钮、输入框或流水内容。 |

## 页面稿与验收

页面稿须展示员工登录、首页、就餐码、资金流水、个人页、终端等待/成功/失败/再次消费，以及手机优先的管理员关键操作和电脑宽屏表格。每张稿标明使用的素材、裁切方式和替代文字。管理端与终端沿用品牌色和标识，不必在高密度资金表单上铺满摄影背景。

最终页面直接使用本目录素材或其保真优化副本；真实二维码由后端 Token 渲染，不能使用插画中的示意二维码。检查手机与终端屏幕尺寸、图片裁切、文字对比度、加载/空/错误状态和键盘可用性。页面稿确认后再完成真实 API 接入和视觉验收。
