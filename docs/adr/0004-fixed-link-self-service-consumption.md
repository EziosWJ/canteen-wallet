# 固定链接自助消费

- 状态：Accepted
- 日期：2026-09-29

所有员工共用一个固定的自助消费链接。员工登录后只可为本人消费；首次登录仍须先修改临时密码。页面根据服务端的食堂当地时间展示当前餐次、餐费，以及本人在该业务日期和餐次已有的未退款消费次数。次数包含扫码、自助消费和人工供餐补录形成的消费；无当前餐次时不能扣款。每笔自助消费都须由员工点击确认，打开链接或预览页面本身不扣款。成功后在员工手机展示与扫码成功页一致的餐次、金额、扣款时间和消费编号，无需工作人员独立核验。

确认时，服务端重新核对餐次、金额和已有消费次数。如果餐次已结束，则拒绝扣款；如果餐次、金额或次数与员工看到的内容不同，则展示更新后的信息并要求再次确认。确认请求的重复提交和网络重试只产生一笔消费；刷新成功页仍返回该笔结果。员工须主动选择“再次消费”，才能开始下一笔确认。余额、账户及登录状态仍按现有消费规则在扣款时校验。这样可以防止过期的预览和并发消费导致员工在不知情的情况下被扣款。

进入自助消费页时，系统自动取消该员工尚未完成的扫码待确认请求，再展示自助消费预览。取消不撤销已经完成的扫码消费；若扫码确认与页面进入同时发生，以服务端先完成的结果为准，随后展示最新消费次数。这使员工切换付费方式时不会留下另一笔可确认的扫码请求。自助消费沿用现有消费资金流水和消费编号，但资金流水须明确标识自助消费来源，不记为终端扫码或管理员操作。
