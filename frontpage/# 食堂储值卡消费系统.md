# 食堂储值卡消费系统
## Mobile Frontend Visual Spec + Implementation Tickets

版本：V1.0  
范围：React 移动端前端  
目标：建立统一视觉规范，并逐步实现登录、首页、就餐码、记录、个人中心、核销等页面。

---

# 1. 背景

当前系统已确定采用：

```text
React
Go Backend
SQLite
Mobile First
```

移动端包含两类主要界面：

```text
员工端 H5
核销终端页面
```

已有视觉参考稿：

```text
登录页
首页
核销页
```

已有视觉素材：

```text
app-logo.png
login-cafeteria-bg.png
home-header-bg.png
phone-qr-illustration.png
default-avatar.png
success-illustration.png
scan-frame.png
footer-waves.png
```

本阶段不重新设计业务逻辑，重点解决：

```text
视觉统一
布局规范
组件复用
页面一致性
移动端适配
后续可维护性
```

---

# 2. 核心目标

前端不得采用“每个页面独立设计”的方式。

必须先建立统一 Design System，然后基于组件和 Token 实现页面。

最终要求：

```text
颜色统一
圆角统一
字号统一
间距统一
阴影统一
状态颜色统一
按钮行为统一
页面宽度统一
底部导航统一
素材使用统一
```

---

# 3. 技术约束

采用：

```text
React
TypeScript
CSS Modules
CSS Variables
Lucide React
```

不引入：

```text
Ant Design Mobile
Material UI
Chakra UI
大型 UI Framework
```

原因：

现有视觉语言已经明确，引入重型组件库会增加样式覆盖成本。

# 6. 字体体系


```text

15px
17px
19px

```

```text

```

```css
--radius-sm: 10px;
--radius-md: 16px;
--radius-lg: 24px;
--radius-xl: 30px;
```

# 9. 阴影体系

普通卡片：

```css
box-shadow:
  0 8px 24px rgba(28, 64, 120, 0.08);
```

浮动按钮：

```css
box-shadow:
  0 12px 32px rgba(22, 139, 255, 0.14);
```

禁止页面单独设计不同风格阴影。

```text

```

如项目已有：


```text

业务逻辑是否变化
```
